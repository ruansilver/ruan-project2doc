# 缓存能力与实际接线

本用例来自1.5.0在EMG仓库上的实测，源码基准为 `a16c0a74f36f910438ba6525195021d101226537`。它检查一个容易被讲错的地方：组件有同步加载能力，并不等于业务入口实际使用了它；故障也要按操作分别解释。

材料从经核对的理解稿中提炼，供后续跨会话回归使用，不依赖原机器的绝对路径。它是特定Spring/Redis案例，不是其他项目必须具备这些技术的通用规则。

1. 给成文者当前Skill、`理解稿片段.md`和`追问.md`，写一段供初学者理解的缓存说明。可用小场景，不要求固定字数；不要只列组件和参数。
2. 给一位新读者成文结果与`追问.md`，不提供理解稿或判定要点，记录逐题答案及正文出处。
3. 核对者读`判定要点.md`，逐题检查是否答得出且正确。错误先区分规则缺陷与执行遗漏，再按研读/成文/审读协议修正。
