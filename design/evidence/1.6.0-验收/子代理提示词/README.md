# 子代理提示词（合成用例）

从会话记录导出的原始提示词（脚本：`../工具/导出子代理提示词.py`）：每个子代理一份文件，按时间顺序列出启动提示词和之后的续发消息。独立读者和盲核对者能接触到的输入，就是这些提示词所指明的文件——这是“读者输入范围”的留档。

本目录只收合成用例（T5、T6、T7）的子代理。真实项目用例（T1–T4）的提示词（`t1-*`、`t2-*`、`t3-study`、`t4-plan`，共 9 份）只留本机，见 `../验收记录.md` 第 7 节。

| 文件 | 用途 | 模型 |
|---|---|---|
| `t5-reader-r1.md` | T5 负例 1 的首轮独立读者（阶段 A、B、C） | sonnet |
| `t5-g3-blind.md` | T5 首轮的 G3 盲核对者（不知道判定要点） | 继承主会话 |
| `t5-fixer.md` | T5 的修复执行者（只读规则、首轮问题材料和源码，没有读判定要点） | 继承主会话 |
| `t5-reader-r2.md` | T5 修复版 1 的复验读者（阶段 A、B、C 与两轮局部复验） | sonnet |
| `t5-reader-r3.md` | T5 修复版 3 的复验读者（阶段 A、B 与两轮局部复验） | sonnet |
| `t5-g3-recheck.md` | T5 复验的 G3 盲核对者（v1、v2 两轮） | 继承主会话 |
| `t6-modify.md` | T6 的修改执行者（被网关超时中断，没有完成） | 继承主会话 |
| `t6-modify-2.md` | T6 的修改执行者（完成） | 继承主会话 |
| `t6-reader.md` | T6 结构类修改后的新独立读者 | sonnet |
| `t6-verify.md` | T6 的盲核对者（含负向判断题） | 继承主会话 |
| `t7-continue.md` | T7“继续生成笔记”的行为单元（只拿到 Skill 文件和旧工程副本） | 继承主会话 |

提示词里的 `src/.work/1.6-验收/…` 路径是测试时的临时工作目录；归档后对应材料在本目录的上一级（`../T5-质量门负例/`、`../T6-修改回归/`、`../T7-规则版本/`），其中读者隔离区在各用例目录下的 `读者隔离区/`。
